# Kurt Royo — Personal Portfolio

A responsive personal portfolio built with semantic HTML and CSS.

## Project structure

- `index.html` — page content
- `styles/style.css` — responsive styles
- `assets/images/` — add your own photos and project images here

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a GitHub repository named `royo-project-1`.
2. Upload/push the contents of this folder to the repository's `main` branch.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait for the published URL to appear in the Pages section.

## Git setup and progress commits

The commit commands above are a suggested sequence for documenting real development stages. Replace `YOUR-USERNAME` with your GitHub username before pushing.

## Personalize before publishing

- Replace the placeholder email `your.email@example.com`.
- Add your actual education, skills, and completed projects.
- Add a profile photo in `assets/images/` if you want one.
- Review all text so it accurately represents you.
